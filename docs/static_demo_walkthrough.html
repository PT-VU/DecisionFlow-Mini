Governed execution

State-machine trace

  1. Intake Agent normalizes the request as an AI-answer complaint and preserves the original ticket.
  2. Evidence Retrieval Agent retrieves source-field records and policy sections POL-AI-001.S01 and POL-REV-001.S03.
  3. Finding Agent creates findings whose locators include source, record, field path, timestamps, and content hash.
  4. Risk & Routing Agent outputs risk=high, action=route_ai_incident_review, and route=ai_governance.
  5. Response Drafting Agent creates a draft but records no refund or sending commitment.
  6. Compliance Gate verifies every finding and response claim, then stops at human_review_required.

Outcome

Safe handoff, not silent automation

The workflow does not issue a refund, confirm that a refund exists, or send a customer message. A reviewer may approve, reject, or request a revision; that action is appended to the audit trail.

Dataset limitation: v0.1 stores these operational facts in structured ticket context. v0.2 will move them to independent payment and AI-conversation sources without changing the finding-to-decision contract.
